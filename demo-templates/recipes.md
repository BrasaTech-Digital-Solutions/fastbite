# Recetas de demostración

Estas recetas son ejemplos para el sandbox. Los alérgenos reflejan solo los ingredientes indicados; las opciones añadidas tienen sus propios alérgenos. Antes de vender, el restaurante debe revisar ingredientes reales, etiquetas de proveedores y contaminación cruzada. ✓ = declarado en la receta base; — = no declarado para esa receta, no una garantía de ausencia.
